# Guia do Usuário - Vaga Certa

## Bem-vindo ao Vaga Certa!

**Vaga Certa** é uma plataforma de empregabilidade que conecta você com as melhores oportunidades de carreira através de inteligência artificial.

### Powered by Manus

Vaga Certa é construído com tecnologias de ponta:
- **Frontend:** React 19 + TypeScript + Tailwind CSS 4
- **Backend:** Node.js + Express + tRPC
- **Database:** MySQL com Drizzle ORM
- **IA:** Integração com LLM avançado (MAIA)
- **Deployment:** Auto-scaling infrastructure com global CDN

---

## Usando Vaga Certa

### 1. **Explorar Vagas**
Acesse a seção "Vagas" para ver oportunidades personalizadas para você. Você pode:
- **Buscar vagas** usando a barra de pesquisa
- **Ver compatibilidade** de cada vaga com seu perfil (em %)
- **Clicar em uma vaga** para ver detalhes completos
- **Salvar vagas** para acompanhar depois

### 2. **Chat com MAIA**
Converse com nossa assistente de IA especializada em empregabilidade. MAIA pode ajudar com:
- Dúvidas sobre vagas e empresas
- Preparação para entrevistas
- Recomendações de cursos
- Dicas de desenvolvimento de carreira
- Análise de seu currículo

Acesse "Chat MAIA" e comece a conversar!

### 3. **Gerenciar Currículos**
Na seção "Currículos", você pode:
- **Upload de currículo** em PDF, DOC ou DOCX
- **Acompanhar status** de cada candidatura
- **Baixar currículos** enviados
- **Ver histórico** de submissões

### 4. **Ver Relatórios**
Acesse "Relatórios" para visualizar:
- **Compatibilidade média** com empresas (anel visual)
- **Total de currículos enviados** no período selecionado
- **Cursos recomendados** para fortalecer seu perfil
- **Filtros temporais** (últimos 7, 30 ou 90 dias)

### 5. **Atualizar Perfil**
Em "Configurações", você pode:
- Editar seus dados pessoais
- Definir preferências de candidatura
- Gerenciar notificações (WhatsApp, Email, Push)
- Revisar privacidade e segurança

## Managing Your Website

Use o painel de gerenciamento (Management UI) para:

- **Preview:** Visualize seu site em tempo real
- **Code:** Acesse todos os arquivos do projeto
- **Dashboard:** Monitore estatísticas e visibilidade
- **Database:** Gerencie dados de vagas, cursos e usuários
- **Settings:** Configure domínio, logo, notificações e secrets
